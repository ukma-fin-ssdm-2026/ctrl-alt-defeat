# Архітектурний огляд (High-Level Design)

## Архітектурний стиль
У проєкті застосовується **Багатошарова (Трирівнева) архітектура (Three-Tier Architecture)**. 
* **Рівень представлення (Presentation Tier):** Клієнтська частина реалізована на React (управління станом, UI-компоненти, пошук).
* **Рівень логіки (Application/Logic Tier):** REST API бекенд на базі фреймворку FastAPI (обробка запитів, бізнес-логіка, авторизація).
* **Рівень даних (Data Tier):** Реляційна база даних PostgreSQL та In-memory сховище Redis (опціонально).

## Опис інтерфейсів між компонентами
Комунікація між компонентами системи відбувається через наступні інтерфейси:
- **UI ↔ REST API Controllers:**
Клієнт взаємодіє з сервером через HTTP-запити, передаючи та отримуючи дані у форматі JSON. Авторизація відбувається за допомогою JWT-токенів у заголовках Authorization: Bearer.
- **Business Logic ↔ TMDB API:**
Сервер виконує зовнішні HTTPS-запити до публічного API для імпорту метаданих про фільми (постери, описи).
- **Data Access Layer ↔ PostgreSQL:** 
Взаємодія з базою даних відбувається через TCP (порт 5432) за допомогою ORM та SQL-запитів.   
- **Data Access Layer ↔ Redis:** 
Отримання та запис кешованих даних та сесій відбувається In-memory по TCP (порт 6379) для зменшення навантаження на основну БД.
