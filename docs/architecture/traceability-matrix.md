## 2. Сценарії атрибутів якості (Quality Attribute Scenarios)

### Сценарій 1: Продуктивність (Performance) - NFR: PERF-001
* **Джерело стимулу (Source):** Наплив 100 одночасних неавторизованих користувачів (Гостей).
* **Стимул (Stimulus):** Користувачі одночасно шукають популярні фільми за назвою та жанром (FR-002).
* **Артефакт (Artifact):** API Server (FastAPI) та PostgreSQL.
* **Середовище (Environment):** Виробниче середовище у години пікового навантаження.
* **Реакція (Response):** FastAPI виконує індексовані запити з пагінацією (`skip`/`limit`) до PostgreSQL, тож обсяг кожної відповіді обмежений. Якщо вимірювання покажуть перевищення порогу, наступним кроком є кешування каталогу в Redis.
* **Міра реакції (Response Measure):** Система успішно обробляє всі запити з часом відгуку менше 500 мс (p95) без виникнення помилок та перевантаження основної бази даних.

### Сценарій 2: Безпека (Security) - NFR: SEC-001
* **Джерело стимулу (Source):** Зловмисний або скомпрометований користувач (T-007, T-032).
* **Стимул (Stimulus):** Користувач намагається відправити відгук (US-002), що містить шкідливий JavaScript-код (XSS-ін'єкція `<script>alert('hack')</script>`).
* **Артефакт (Artifact):** Модуль валідації в FastAPI (Backend) та механізм зберігання сесій.
* **Середовище (Environment):** Публічний доступ до виробничого середовища через Інтернет (TB-01).
* **Реакція (Response):** FastAPI та Pydantic валідують і санітизують поля введення, відхиляючи небезпечний контент. Токени автентифікації зберігаються виключно в `HttpOnly`, `Secure` cookies, унеможливлюючи їх крадіжку через XSS у разі помилки відображення.
* **Міра реакції (Response Measure):** 100% небезпечних скриптів заблоковано або екрановано; токени захищені від читання через JavaScript; система повертає HTTP 400/422; дані користувачів у безпеці.

### Сценарій 3: Надійність та Доступність (Reliability / Availability) - NFR: REL-001
* **Джерело стимулу (Source):** Аварійне завершення процесу бекенду або тимчасова втрата зв'язку із зовнішнім сервісом TMDB API.
* **Стимул (Stimulus):** Один із воркерів FastAPI/Uvicorn аварійно завершує роботу під час запиту, або зовнішній TMDB API повертає помилку 503 Service Unavailable.
* **Артефакт (Artifact):** Process Supervisor / Docker Container, Health Check ендпоінт (`/health`), PostgreSQL Transaction Manager.
* **Середовище (Environment):** Виробниче середовище (Production).
* **Реакція (Response):** Process Supervisor (Docker) автоматично перезапускає аварійний воркер за лічені секунди. При збої TMDB сервер застосовує патерн Fallback і віддає збережені в PostgreSQL метадані. Незавершені запити на зміну даних у БД безпечно скасовуються за допомогою `ROLLBACK` транзакцій.
* **Міра реакції (Response Measure):** Середній час відновлення процесу (MTTR) становить < 30 секунд; щомісячний Uptime системи перевищує 99.0% (сумарний простій не більше 7.3 годин на місяць); цілісність даних збережена.

### Сценарій 4: Підтримуваність (Maintainability) - NFR: MAINT-001
* **Джерело стимулу (Source):** Розробник.
* **Стимул (Stimulus):** Розробник створює Pull Request (PR) із логікою для рекомендацій (FR-007) або інтеграції TMDB (FR-012) для злиття у гілку `main`.
* **Артефакт (Artifact):** CI/CD пайплайн (GitHub Actions) та вихідний код бекенду (FastAPI).
* **Середовище (Environment):** Середовище розробки та автоматизованого тестування.
* **Реакція (Response):** CI-сервер автоматично збирає проєкт, запускає перевірки стилю (Ruff, Black), сканери безпеки (Bandit, Gitleaks), модульні тести та генерує звіт про тестове покриття коду.
* **Міра реакції (Response Measure):** Якщо покриття коду становить менше 80% або знайдено критичні проблеми безпеки, пайплайн блокує можливість злиття PR до виправлення зауважень.

### Сценарій 5: Сумісність (Compatibility) - NFR: COMP-001
* **Джерело стимулу (Source):** Кінцевий користувач.
* **Стимул (Stimulus):** Користувач відкриває вебдодаток через мобільний браузер (Safari на iOS) або браузер з нестандартною роздільною здатністю екрана.
* **Артефакт (Artifact):** Frontend-додаток (React) та його UI-компоненти на базі Tailwind CSS.
* **Середовище (Environment):** Виробниче середовище, мобільна мережа або Wi-Fi.
* **Реакція (Response):** Інтерфейс React-додатка адаптивно підлаштовується під розмір екрана (Responsive Design). Навігація згортається у мобільне меню, а картки фільмів перебудовуються в адаптивну сітку.
* **Міра реакції (Response Measure):** 100% ключових функцій (пошук, оцінювання, списки, коментарі) залишаються повнофункціональними без горизонтальної прокрутки у двох останніх мажорних версіях Chrome, Safari, Firefox та Edge.
