## 2. Сценарії атрибутів якості (Quality Attribute Scenarios)

### Сценарій 1: Продуктивність (Performance) - NFR: PERF-001
* **Джерело стимулу (Source):** Наплив 100 одночасних неавторизованих користувачів (Гостей).
* **Стимул (Stimulus):** Користувачі одночасно шукають популярні фільми за назвою та жанром (FR-002).
* **Артефакт (Artifact):** Кешуючий шар (Redis) та API Server (FastAPI).
* **Середовище (Environment):** Виробниче середовище у години пікового навантаження.
* **Реакція (Response):** FastAPI перехоплює GET-запити і, замість виконання складних вибірок `ILIKE` у PostgreSQL, миттєво віддає збережені JSON-дані з оперативної пам'яті Redis.
* **Міра реакції (Response Measure):** Система успішно обробляє всі запити з часом відгуку менше 500 мс без виникнення помилок та перевантаження основної бази даних.

### Сценарій 2: Безпека (Security) - NFR: SEC-001
* **Джерело стимулу (Source):** Заблокований користувач-порушник.
* **Стимул (Stimulus):** Користувач намагається відправити HTTP-запит (наприклад, через Postman) для створення нової рецензії (FR-004), ігноруючи блокування UI фронтенду.
* **Артефакт (Artifact):** Модуль авторизації та перевірки прав доступу (FastAPI Dependency).
* **Середовище (Environment):** Виробниче середовище.
* **Реакція (Response):** Глобальна залежність у FastAPI перевіряє JWT токен, витягує `user_id`, робить запит до БД і бачить, що значення `banned_until` (FR-009) більше за поточний час. Система відхиляє запит до того, як він дійде до логіки створення рецензії.
* **Міра реакції (Response Measure):** Запит відхилено зі статусом 403 Forbidden. Дані бази даних залишаються незмінними.

### Сценарій 3: Надійність (Reliability) - NFR: REL-001
* **Джерело стимулу (Source):** Внутрішній апаратний збій або втрата мережевого з'єднання.
* **Стимул (Stimulus):** Процес обробки запиту переривається рівно в момент збереження нової оцінки (FR-003) в базу даних та перерахунку загального рейтингу фільму.
* **Артефакт (Artifact):** Транзакційний менеджер PostgreSQL та ORM FastAPI.
* **Середовище (Environment):** Виробниче середовище.
* **Реакція (Response):** Реляційна база даних виявляє, що ланцюг транзакції не було завершено успішно (не отримано `COMMIT`). Система автоматично виконує `ROLLBACK`, скасовуючи частково записані дані.
* **Міра реакції (Response Measure):** База даних залишається у консистентному стані, рейтинг фільму не спотворюється. Користувачу повертається HTTP 500 із пропозицією повторити дію.

### Сценарій 4: Підтримуваність (Maintainability) - NFR: MAINT-001
* **Джерело стимулу (Source):** Розробник.
* **Стимул (Stimulus):** Розробник створює Pull Request (PR) із логікою для рекомендацій (FR-007) для злиття у гілку `main`.
* **Артефакт (Artifact):** CI/CD пайплайн та вихідний код бекенду (FastAPI).
* **Середовище (Environment):** Середовище розробки та тестування (наприклад, GitHub Actions).
* **Реакція (Response):** CI-сервер автоматично збирає проєкт, запускає всі модульні тести та генерує звіт про тестове покриття коду.
* **Міра реакції (Response Measure):** Якщо покриття коду становить менше 80%, пайплайн блокує можливість злиття PR, доки розробник не допише тести для нових ендпоінтів.
