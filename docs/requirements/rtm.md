## Техніки тест-дизайну (Test Design Techniques)

У межах планування та розробки тестових наборів застосовано такі формальні техніки:

### 1. Еквівалентне розбиття (Equivalence Partitioning)
* **Рейтинг рецензії (шкала 1–10):**
  * Клас 1 (Валідний): Цілі числа $R \in [1, 10]$ $\rightarrow$ 201 Created.
  * Клас 2 (Невалідний, нижче норми): $R \le 0$ $\rightarrow$ 422 Validation Error.
  * Клас 3 (Невалідний, вище норми): $R > 10$ $\rightarrow$ 422 Validation Error.
* **Модерація контенту (SEC-002):**
  * Клас 1 (Чистий текст): Звичайний текст без заборонених паттернів $\rightarrow$ прийнято.
  * Клас 2 (Спам-посилання): Текст містить `http://` або `https://` $\rightarrow$ 400 Bad Request (`POLICY_VIOLATION: spam_links`).
  * Клас 3 (Ненормативна лексика): Обсценні слова та обфускації (sh1t, f*ck) $\rightarrow$ 400 Bad Request (`POLICY_VIOLATION: profanity`).
  * Клас 4 (Крик): Текст довжиною > 20 символів з > 80% великих літер $\rightarrow$ 400 Bad Request (`POLICY_VIOLATION: shouting`).

### 2. Аналіз граничних значень (Boundary Value Analysis)
* **Довжина тексту рецензії ($10 \le L \le 5000$):**
  * $L = 9$ (грань $- 1$): 422 Unprocessable Entity.
  * $L = 10$ (нижня грань): 201 Created.
  * $L = 200$ (номінальне значення): 201 Created.
  * $L = 5000$ (верхня грань): 201 Created.
  * $L = 5001$ (грань $+ 1$): 422 Unprocessable Entity.
* **Рейтинг рецензії ($1 \le R \le 10$):**
  * $R = 0$ (невалідна грань): 422.
  * $R = 1$ (мінімальна валідна грань): 201.
  * $R = 10$ (максимальна валідна грань): 201.
  * $R = 11$ (невалідна грань): 422.
