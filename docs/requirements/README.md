# Вимоги до системи (Requirements)

У цьому розділі зафіксовано повний обсяг вимог до веб-платформи **ctrl-alt-defeat** (Лабораторна робота 2).

## Артефакти вимог

1. **[Вимоги до системи (requirements.md)](./requirements.md)**  
   Містить 12 функціональних вимог (FR-001 – FR-012) та 6 нефункціональних вимог за категоріями ISO 25010 (REL-001, PERF-001, SEC-001, SEC-002, MAINT-001, COMP-001).

2. **[Користувацькі історії (user-stories.md)](./user-stories.md)**  
   11 користувацьких історій (US-001 – US-011) у форматі «Як <роль>, я хочу <можливість>, щоб <вигода>», кожна з детальними критеріями прийняття та верифікацією за критеріями **INVEST**.

3. **[Матриця простежуваності вимог (rtm.md)](./rtm.md)**  
   Двонаправлена матриця простежуваності (RTM), що пов'язує користувацькі історії, системні вимоги (FR/NFR) та унікальні ідентифікатори тестів (T-001 – T-038).

4. **[Сценарії використання (use-cases.md)](./use-cases.md)**  
   Деталізовані сценарії використання системи для гостей, зареєстрованих користувачів та адміністраторів.
