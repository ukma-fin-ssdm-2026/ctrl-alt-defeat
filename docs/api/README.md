# Документація API (API Specification & Design)

У цьому розділі розміщено специфікації інтерфейсу прикладного програмування (REST API) платформи **ctrl-alt-defeat** (Лабораторна робота 4).

## Артефакти API

1. **[Дизайн REST API (api-design.md)](./api-design.md)**  
   Опис базової адреси, стилю API, стратегії версіонування, структури ресурсів та CRUD-операцій над рецензіями (`/api/v1/reviews`).

2. **[Специфікація OpenAPI (openapi-generated.yaml)](./openapi-generated.yaml)**  
   Автоматично згенерована схема OpenAPI 3.1.0 за підходом Code-First безпосередньо з FastAPI-застосунку.

3. **[Атрибути якості API (quality-attributes.md)](./quality-attributes.md)**  
   Кількісно вимірювані цілі за атрибутами продуктивності, безпеки, надійності та підтримуваності з умовами провалу, описом реалізації та аналізом архітектурних компромісів.

4. **[Інтерактивна документація Swagger (index.html)](./index.html)**  
   Веб-сторінка з інтерактивним інтерфейсом Swagger UI, що хоститься на [GitHub Pages](https://ukma-fin-ssdm-2026.github.io/ctrl-alt-defeat/).
