# Журнал налагодження (Debugging Log)

**Симптом:**
При спробі запустити модульні тести командою pytest tests/ виконання негайно переривалося на етапі збору тестів. З'являлася помилка ModuleNotFoundError: No module named 'sqlalchemy' для файлів test_main.py та test_reviews.py.

**Причина:**
Запуск тестів відбувався на одному окремому девайсі людини, яка писала ці тести. Також до цього виконання коду відбувалося через глобальний інтерпретатор Python системи (macOS). Проєкту не вистачало файлу requirements.txt, а віртуальне середовище (venv) не використовувалося для ізоляції та підключення необхідних бібліотек (зокрема sqlalchemy, fastapi тощо).

**Виправлення:**
1. Створено файл requirements.txt з переліком усіх залежностей.
2. Створено та активовано віртуальне середовище (python3 -m venv venv, source venv/bin/activate).
3. Встановлено залежності (pip install -r requirements.txt).
4. Тести запущено через модуль активного середовища: python -m pytest src/api/tests/.
Тепер базові тести у tests/test_main.py та test_reviews.py успішно проходять, що підтверджує коректність роботи середовища.

**Урок:**
Завжди фіксувати залежності у requirements.txt з першого дня розробки та переконуватися, що термінал працює в контексті віртуального середовища ((venv) у запрошенні командного рядка) перед виконанням будь-яких скриптів чи тестів.
