# Опис проєкту: Сайт рецензій та рекомендацій фільмів і серіалів

## 1. Опис ідеї проєкту
Проєкт являє собою веб-платформу для кіноманів та любителів серіалів, яка дозволяє відкривати для себе новий контент, вести облік переглянутого та ділитися враженнями. Зважаючи на величезну кількість доступних шоу в жанрах наукової фантастики, містики та драми, користувачам часто важко знайти щось якісне для перегляду. 

Система розв'яже цю проблему, надаючи можливість оцінювати контент, писати рецензії та отримувати персоналізовані рекомендації. Платформа об'єднає функціонал бази даних та соціального трекера (аналог Letterboxd або міні-IMDb).

## 2. Визначені ролі користувачів
- **Гість (Анонімний користувач):** Може переглядати каталог, шукати фільми/серіали, читати рецензії та бачити загальний рейтинг.
- **Користувач (Авторизований):** Може ставити оцінки, писати рецензії, отримувати рекомендації, додавати контент у список "До перегляду".
- **Адміністратор:** Має права на додавання/редагування інформації про контент, модерацію (видалення неприйнятних відгуків) та блокування порушників.

## 3. Високорівневий список функцій
1. **Автентифікація та профілі:** Реєстрація, вхід та управління профілем користувача.
2. **Каталог та пошук:** Фільтрація контенту за жанрами, роками та пошук за назвою.
3. **Система оцінювання:** Виставлення балів (1-10) та написання текстових рецензій до фільмів/серіалів.
4. **Управління списками:** Формування особистого списку "До перегляду" (Watchlist).
5. **Рекомендації:** Генерація пропозицій на основі історії високих оцінок користувача (наприклад, рекомендація подібних шоу після перегляду *11.22.63* чи *Stranger Things*).
6. **Панель модерації:** Інтерфейс для адміністраторів для управління контентом та рецензіями.

## 4. Міні-ТЗ

**1. Призначення системи:** 
Система розв'язує проблему пошуку якісного відеоконтенту для глядачів, дозволяючи їм знаходити фільми та серіали на основі відгуків спільноти та персоналізованих алгоритмів рекомендацій.

**2. Межі системи:** 
- *Входить в обсяг:* Реєстрація користувачів, каталог фільмів/серіалів, рейтинги та рецензії, списки "До перегляду", базові рекомендації за жанром/оцінками.
- *Поза обсягом:* Стрімінг відеоконтенту (ми не хостимо відео), соціальні мережеві функції (додавання в друзі, чати), монетизація та підписки, мобільний застосунок (реалізується лише веб-версія).

**3. Ролі користувачів і що кожна з них може робити:** 
- *Гість:* перегляд каталогу та читання рецензій.
- *Користувач:* оцінювання, написання рецензій, ведення особистого списку переглядів, отримання рекомендацій.
- *Адміністратор:* модерація відгуків, блокування користувачів, управління наповненням бази даних.

**4. Ключові функції:** 
1. *Автентифікація:* Безпечна реєстрація та авторизація користувачів.
2. *Пошук і фільтрація:* Знаходження контенту за назвою, жанром (наприклад, містика, драма) чи роком.
3. *Рецензування:* Додавання текстових відгуків та бальних оцінок.
4. *Рекомендаційна система:* Пропозиція фільмів на основі схожих вподобань.
5. *Watchlist:* Збереження контенту для майбутнього перегляду.
6. *Модерація:* Видалення спаму та порушень з відгуків.

**5. Нефункціональні вимоги:** 
1. *Продуктивність:* Сторінка каталогу та пошуку повинна завантажуватися і відповідати за час не більше 500 мс при 100 одночасних користувачах.
2. *Безпека:* Усі паролі користувачів повинні зберігатися в базі даних виключно у хешованому вигляді (наприклад, з використанням алгоритму bcrypt), а сесії передаватися через HTTPS.
3. *Надійність:* Система повинна мати показник доступності (uptime) не менше 99% протягом місяця.

**6. Припущення та обмеження:** 
- *Стек:* Бекенд реалізується мовою Python (FastAPI, Django або Flask), фронтенд – базовий HTML/CSS/JS (або React), база даних – PostgreSQL або SQLite.
- *Зовнішні сервіси:* Дані про фільми (постери, описи) імпортуватимуться через публічне API (наприклад, TMDB API).
